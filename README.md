# 💝 Valentine's Day Surprise Website 💝

A beautiful, interactive Valentine's Day surprise website with animations, confetti, and heartfelt messages.

## Features ✨

- **Interactive Button** - Click to reveal the surprise
- **Animated Hearts** - Bouncing heart emojis
- **Love Letter** - Heartfelt message display
- **Confetti Effect** - Celebration animation when clicking "Yes"
- **Runaway No Button** - The "No" button playfully escapes from your cursor
- **Responsive Design** - Works on mobile and desktop
- **Beautiful Gradient Background** - Purple and pink gradients
- **Twinkling Stars** - Animated starfield background
- **Smooth Animations** - CSS animations throughout

## How to Use 🎁

1. Open `index.html` in your browser
2. Click the "Click Me!" button to reveal the surprise
3. Enjoy the love letter and animations
4. Click "Yes" for a confetti celebration!
5. Try clicking "No" to see the button run away
6. Click "Do it Again?" to restart

## Files 📁

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality
- `README.md` - This file

## Customization 🎨

You can easily customize:
- Colors in `styles.css`
- Messages in the love letter (index.html)
- Button text and actions (script.js)
- Animations and timings
